# 📦 InventoPro - Inventory Management Landing Page

A modern, responsive, and interactive Inventory Management landing page built using pure HTML, CSS, and JavaScript.

## 🚀 Features

- Responsive Design (Mobile, Tablet, Desktop)
- Modern SaaS-style UI
- Sticky Navigation Bar
- Mobile Hamburger Menu
- Hero Section with Call-to-Action
- Inventory Dashboard Preview
- Animated Statistics Counter
- Feature Cards
- Smooth Scrolling Navigation
- Call-to-Action Section
- Clean and Reusable Code Structure
- No External Frameworks Required

---

## 🎨 Customization

### Change Brand Name

Locate:

```html
<div class="logo">InventoPro</div>
```

Replace with your desired brand name.

### Change Theme Colors

Update the primary color values in CSS:

```css
#06b6d4
#22d3ee
#2563eb
```

### Update Statistics

Edit the values inside:

```html
data-target="500"
data-target="25000"
data-target="99"
data-target="120"
```
